# MathIt – מסע בעולם החשבון

אפליקציית רשת לטלפון ללימוד ותרגול חשבון לילדים, בעברית: מסע עם שיעורים מונפשים, מיני-משחקים, חידות ובוסים, בעולמות לבחירה – פיות, כדורגל, כדורסל ונינג׳ה.

- **לשחק:** https://liorhen9.github.io/mathit/ (אפשר "להוסיף למסך הבית" ולשחק גם בלי אינטרנט)
- כל המידע נשמר בטלפון בלבד. בלי חשבונות, בלי שרת ובלי פרסומות.
- תכנון: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · מפת דרכים: [docs/ROADMAP.md](docs/ROADMAP.md)
- אח בכור: [ChessIt](https://github.com/LiorHen9/ChessIt)

## פיתוח

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בדיקת טיפוסים + בנייה
```

כל דחיפה ל-`main` נבנית ומתפרסמת ב-GitHub Pages (`.github/workflows/deploy.yml`).

הגופן Rubik (SIL OFL 1.1) נמצא ב-`public/fonts`. הקוד ברישיון GPL-3.0-or-later.
