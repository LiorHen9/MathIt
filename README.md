# MathIt – מסע בעולם החשבון

![MathIt](public/og-image.png)

אפליקציית רשת לטלפון ללימוד ותרגול חשבון לילדים, בעברית: מסע של עשרה פרקים עם שיעורים מונפשים, מיני-משחקים, חידות ובוסים – מהמנייה הראשונה בגן חובה ועד שברים, עשרוניים, שטח והיקף בכיתה ו׳. בשישה עולמות לבחירה: פיות, כדורגל, כדורסל, נינג׳ה, קוביות וכוכבות הבמה.

**לשחק:** https://liorhen9.github.io/MathIt/ – בטלפון: "הוספה למסך הבית", ואחרי הפעם הראשונה זה עובד גם בלי אינטרנט.

## מה יש בפנים
- **מסע** – 10 פרקים, שיעור לכל נושא, תרגולים ברמות עולות, תיבות אוצר, חידות (ריבוע קסם, מאזניים, מספר חסר, KenKen) ובוס בסוף כל פרק, עם חגיגת סוף פרק ותעודת סיום בסוף המסע.
- **אנימציות שמלמדות** – מסגרת עשר, קוביות ומוטות, ציר מספרים, מערך לכפל, פיצה לשברים, מאונך, שעון – בשיעור, ברמז ובהסבר אחרי טעות.
- **מותאם לכל ילד** – מבחן מיקום, רמה שעולה ויורדת לפי התשובות, חזרות כשהגיע הזמן, הישגים.
- **כמה ילדים בטלפון אחד** – פרופיל לכל ילד, PIN אם רוצים, ופנייה נכונה בעברית (בן/בת).
- **להורים** – אזור מוגן: איפה הילד במסע, מה נשלט ומה קשה, זמן תרגול, יעד יומי, משחקים כבויים, גיבוי ושחזור.

## פרטיות
הכול נשמר בטלפון בלבד: בלי הרשמה, בלי שרת, בלי פרסומות ובלי מעקב. כדי לא לאבד התקדמות כדאי לגבות מדי פעם (אזור ההורים ← גיבוי).

## פיתוח

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בדיקת טיפוסים + בנייה
```

כל דחיפה ל-`main` נבנית ומתפרסמת ב-GitHub Pages (`.github/workflows/deploy.yml`). בדיקות ובנייה בלי npm: `scripts/local-check.sh` (ראו `CLAUDE.md`).
